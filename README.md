# IELTS Topic Draw

A lightweight IELTS Speaking practice tool that randomly draws a Part 2 topic and reveals its paired Part 3 discussion questions.

## Features

- No repeated topic until the current pool is exhausted
- Undo, redo, and session reset
- Topic-family filters
- Separate Part 3 reveal
- Responsive phone and desktop layouts
- Keyboard shortcuts: `N` for next topic, `Enter`/`Space` to reveal, and `Ctrl/Cmd + Z` to undo

The initial version contains 12 demonstration topics. The topic data is stored near the bottom of `index.html` in the `topics` array.
